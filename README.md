# Sistema de Turnos

Sistema web para la gestión de turnos de un consultorio médico.

El sistema permitirá gestionar pacientes, profesionales y turnos, facilitando la organización de las consultas médicas.

Proyecto correspondiente a la materia "Metodología de Sistemas II" de la Tecnicatura Universitaria en Programación.

- PostgreSQL

## Requisitos

Antes de comenzar, es necesario tener instalado:

- Node.js 24.20.0
- npm
- Git

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/ignaciorlabadie/sistema-de-turnos.git
```

Ingresar al proyecto:

```bash
cd sistema-de-turnos
```

Instalar las dependencias:

```bash
npm ci
```

## Ejecución

Para levantar el proyecto:

```bash
npm run dev
```
